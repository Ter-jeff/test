# AutogenOasisIntegration

## Local Development

Before starting any debugging or development, make sure your local configuration is properly set up.

### Setup Steps

1. Copy `appsettings.Sample.csv` and rename it to `appsettings.Development.csv`.
2. Update the values in `appsettings.Development.csv` to match your local environment.
3. Run the command `PowerShell: Launch Main File (Development)` to verify that your configuration is correct.
